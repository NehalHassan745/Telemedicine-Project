This project presents a low-cost, IoMT-based telemedicine system designed to monitor real-time vital signs specifically Heart Rate (HR) and Oxygen Saturation (SpO₂) using the MAX30102 pulse oximetry sensor interfaced with an ESP32 Wi-Fi microcontroller. The data are transmitted wirelessly to a centralized web-based telemedicine dashboard developed by the instructor (HITEC IoMT Telemedicine Dashboard), where each student group maintains an individual patient node. Our group implemented IoMT-Node05, registered under the patient’s name "Raina Amer," and successfully streamed live physiological data visible to the entire class. The system demonstrates the core workflow of an Internet of Medical Things (IoMT) architecture: sensor acquisition, embedded firmware processing, Wi-Fi transmission, and cloud-based clinical visualization illustrating how remote patient monitoring (RPM) can be practically realized using affordable offthe-shelf hardware.
